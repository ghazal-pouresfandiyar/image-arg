================================================================================
  ANALYSIS FOLDER — File Reference Guide
================================================================================

LOCATION: user_interfaces/evaluation/analysis/

This folder contains scripts and outputs for the descriptive statistics
analysis of the Image-Argument Evaluation project.

--------------------------------------------------------------------------------
  WORKFLOW
--------------------------------------------------------------------------------

STEP 1: Generate Output
    Run:  python3 run.py
    This runs all 4 analysis scripts and stores results in output/ folder.

STEP 2: Generate Detailed Presentation (optional)
    Run:  python3 generate_presentation.py
    This reads the output/ folder and generates output/presentation.html
    (requires output/ to exist first — run run.py first).

STEP 3: Simple Presentation (already generated)
    The file output/present_simple.html was generated by AI (ChatGPT) based
    on the output/ folder contents. It does NOT require any script to run —
    just open it in a browser.

--------------------------------------------------------------------------------
  SCRIPTS
--------------------------------------------------------------------------------

1. descriptive_stats.py
   - Reads: evaluations_export_final.json
   - Does: Flattens the nested JSON into a table, computes descriptive
     statistics (percentages, counts, means) for all 12 metrics.
   - Output: output/evaluations_flattened.csv, prints stats to console.

2. visualizations.py
   - Reads: evaluations_export_final.json
   - Does: Generates bar charts (stacked) for each categorical metric,
     box plots for numerical metrics, and a pie chart for model distribution.
   - Output: output/*_chart.png, output/numerical_metrics_charts.png,
     output/model_distribution_chart.png.

3. comprehensive_report.py
   - Reads: evaluations_export_final.json
   - Does: Writes a full text report with all statistics, percentages,
     and model comparisons.
   - Output: output/full_analysis_report.txt.

4. profiling_report.py
   - Reads: evaluations_export_final.json
   - Does: Generates an interactive HTML profiling dashboard using
     ydata-profiling (distributions, correlations, missing values).
   - Output: output/evaluation_profiling_report.html.

5. run.py (MASTER SCRIPT)
   - Does: Runs all 4 scripts above in order. This is the entry point.
   - Usage: python3 run.py

6. generate_presentation.py
   - Reads: output/ folder (charts, CSV) + evaluations_export_final.json
   - Does: Generates a comprehensive HTML presentation with embedded
     charts, statistics, and academic-style interpretation.
   - Output: output/presentation.html
   - Note: Must run run.py first to generate the output/ contents.

--------------------------------------------------------------------------------
  DATA SOURCE
--------------------------------------------------------------------------------

evaluations_export_final.json
  Location: user_interfaces/evaluation/ (parent folder)
  Structure: Nested JSON with 46 images x 3 models (llava, minicpm, nemotron)
  Metrics: 10 categorical + 2 numerical per evaluation

--------------------------------------------------------------------------------
  NOTES
--------------------------------------------------------------------------------

- All scripts read from evaluations_export_final.json (no space in filename).
- Charts are generated by matplotlib (non-interactive backend).
- The profiling report requires ydata-profiling package.
- present_simple.html is self-contained (charts embedded as base64).
- presentation.html is also self-contained (charts embedded as base64).
